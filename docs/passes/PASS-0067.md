# PASS-0067 Offline Detection & Device Health

## Objective

Calculate live device health from heartbeat age instead of relying only on stored device status.

## Health Rules

Online:

last_seen_at <= 2 minutes

Warning:

last_seen_at > 2 minutes and <= 10 minutes

Offline:

last_seen_at > 10 minutes or missing

## Files Updated

- apps/api/src/routes/devices.ts
- apps/api/src/routes/dashboard.ts

## API Changes

GET /devices now returns:

- computed_status
- minutes_since_seen
- status overwritten with computed_status for UI compatibility

GET /devices/:id now returns the same computed health fields.

GET /dashboard/metrics now uses computed health status.
