# PASS-0083 Tenant Lifecycle Management

## Objective

Add tenant detail and lifecycle management tools to the platform admin area.

## Scope

- Tenant detail API
- Tenant detail page
- Edit tenant name
- Edit status
- Edit plan
- Edit selected product
- Reset onboarding
- Soft delete tenant
- Show tenant users
- Show tenant metrics
- Show recent tenant audit logs

## URL

https://app.hi5central.com/admin/platform/tenants/:id

## API

- GET /platform-admin/tenants/:id
- PATCH /platform-admin/tenants/:id
- POST /platform-admin/tenants/:id/reset-onboarding
- POST /platform-admin/tenants/:id/soft-delete
