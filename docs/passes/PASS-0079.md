# PASS-0079 Platform Admin Navigation and Tenant Operations

## Objective

Improve platform admin usability with a dedicated navigation shell and tenant lifecycle actions.

## Scope

- Platform admin navigation shell
- Platform overview page updated
- Tenants/users pages moved into platform admin shell
- Placeholder pages for trials, audit log, and system health
- Tenant activate action
- Tenant suspend action
- Tenant convert trial action

## URLs

- /admin/platform
- /admin/platform/tenants
- /admin/platform/users
- /admin/platform/trials
- /admin/platform/audit
- /admin/platform/system

## API

- POST /platform-admin/tenants/:id/status
- POST /platform-admin/tenants/:id/convert-trial
