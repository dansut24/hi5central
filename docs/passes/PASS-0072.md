# PASS-0072 Trial Signup & Tenant Onboarding

## Objective

Design and begin the public trial signup flow for Hi5Central.

## Flow

1. User clicks Start Free Trial on hi5central.com
2. User enters company and admin details
3. API creates tenant
4. API creates first super admin user
5. User is redirected to app.hi5central.com/onboarding
6. User completes initial configuration
7. User lands in the Control dashboard

## Required API

POST /auth/trial-signup

## Required Fields

- company_name
- tenant_slug
- first_name
- last_name
- email
- password

## Created Records

- tenant
- user
- membership
- default device group
- default branding
- starter subscription/trial record
