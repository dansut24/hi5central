# PASS-0074 Tenant Login and Onboarding Wizard

## Objective

Create a styled tenant subdomain login and onboarding experience.

## Scope

- Tenant login page at tenant.hi5central.com/login
- Tenant onboarding page at tenant.hi5central.com/onboarding
- Product selection
- Tenant branding placeholder
- Device enrolment placeholder
- Onboarding completion API
- Wildcard Caddy API routing for tenant subdomains

## Infrastructure Dependency

Wildcard tenant subdomains must be active:

*.hi5central.com

Wildcard TLS must be issued by Caddy using the IONOS DNS challenge.
