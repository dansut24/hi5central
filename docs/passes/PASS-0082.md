# PASS-0082 Safe Tenant Impersonation Handoff

## Objective

Fix tenant impersonation so the platform admin session on app.hi5central.com is not overwritten.

## Problem

The original impersonation flow created the tenant owner session directly on app.hi5central.com.

This caused the platform admin to lose their admin session and receive 403 forbidden on platform routes.

## Solution

Use a one-time impersonation handoff token.

Flow:

1. Platform admin clicks Impersonate on app.hi5central.com
2. API creates a short-lived one-time token
3. Browser redirects to tenant.hi5central.com/impersonate?token=TOKEN
4. Tenant subdomain consumes token through /api/auth/impersonation/consume
5. Tenant session is created on the tenant subdomain
6. Platform admin session remains intact on app.hi5central.com

## Security

- Requires platform_admin to create token
- Token expires after 5 minutes
- Token is single-use
- Token is stored hashed
- Impersonation is audit logged
