# PASS-0068 Device Actions Framework

## Objective

Create the server-side action queue foundation used by future agent commands.

## Scope

- Device action table
- Portal action creation endpoint
- Device action history endpoint
- Agent pending action polling endpoint
- Agent action start endpoint
- Agent action completion endpoint

## Supported Initial Actions

- refresh_inventory
- reboot
- shutdown

## Files Added

- packages/db/migrations/006_device_actions.sql
- apps/api/src/routes/actions.ts

## Files Updated

- packages/db/src/types.ts
- apps/api/src/index.ts

## API Endpoints

Create action:

POST /devices/:id/actions

List device actions:

GET /devices/:id/actions

Agent poll pending actions:

GET /agent/devices/:id/actions

Agent mark action running:

POST /agent/actions/:id/start

Agent mark action complete:

POST /agent/actions/:id/complete
