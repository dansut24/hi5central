# PASS-0075 Email Verification Delivery

## Objective

Send tenant trial confirmation emails using SMTP and tenant-branded confirmation links.

## Scope

- SMTP configuration
- Nodemailer mail helper
- Trial confirmation email template
- Confirmation token delivery
- Tenant subdomain confirmation URL
- Confirmation redirect to tenant login

## Confirmation Flow

Signup:

https://hi5central.com/signup

Email confirmation link:

https://tenant-slug.hi5central.com/api/auth/confirm-trial?token=TOKEN

API confirms:

- Email verification token
- User activation
- Tenant activation

Redirect:

https://tenant-slug.hi5central.com/login?verified=1

Then:

- User logs in
- User is redirected to onboarding
- User completes tenant setup
