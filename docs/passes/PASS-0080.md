# PASS-0080 Tenant Impersonation

## Objective

Allow Hi5Central platform administrators to impersonate a tenant owner from the platform admin tenant list.

## Scope

- Add platform impersonation API route
- Register impersonation route
- Add impersonate button to platform tenant list
- Create tenant owner session
- Redirect platform admin into tenant dashboard

## URL

Platform source:

https://app.hi5central.com/admin/platform/tenants

Tenant target:

https://tenant-slug.hi5central.com/dashboard

## Security

- Requires authenticated session
- Requires platform_admin role
- Platform admin role is checked directly from the database
- Impersonation chooses the tenant owner membership
- Impersonation event is written to audit log

## Result

PASS
