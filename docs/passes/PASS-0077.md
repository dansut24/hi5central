# PASS-0077 Platform Admin Tenants and Users

## Objective

Add a basic platform admin area for testing tenants and users.

## Scope

- List tenants
- Delete tenants
- List users
- Delete users
- Basic platform admin UI pages

## URLs

- /admin/platform/tenants
- /admin/platform/users

## API Endpoints

- GET /platform-admin/tenants
- DELETE /platform-admin/tenants/:id
- GET /platform-admin/users
- DELETE /platform-admin/users/:id

## Security Note

This pass is intended for testing/admin bootstrap.

A later pass must add platform-admin-only RBAC protection before production use.
