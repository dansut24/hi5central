# PASS-0086 AI Provider Settings

## Objective

Add tenant-level AI provider settings with encrypted API key storage.

## Scope

- Added tenant_ai_settings database table
- Added APP_ENCRYPTION_KEY support
- Added AES-256-GCM secret encryption helper
- Added AI settings API
- Added AI settings UI
- Added support for:
  - Disabled
  - OpenAI
  - Anthropic Claude
  - Azure OpenAI
  - Ollama / Local AI

## URL

https://tenant.hi5central.com/admin/integrations/ai

## API

- GET /ai-settings/providers
- GET /ai-settings
- PUT /ai-settings

## Security

- Requires authenticated tenant session
- API keys are encrypted before database storage
- API keys are never returned in plaintext
- UI displays only masked key status
- APP_ENCRYPTION_KEY is stored only in VPS .env
- OpenAI API key is entered via tenant admin UI, not committed to code

## Result

PASS
