# PASS-0085 Integration Framework

## Objective

Create a generic tenant integration framework before adding individual providers.

## Scope

- tenant_integrations database table
- Integration catalogue
- Tenant integrations API
- Tenant admin integrations page
- Enable/disable integration records

## Categories

- AI
- Remote Access
- PSA / Service Desk
- Identity
- Messaging
- Email
- Storage

## URL

https://tenant.hi5central.com/admin/integrations

## API

- GET /integrations/catalogue
- GET /integrations
- POST /integrations/:provider/toggle

## Security

Requires authenticated tenant session.
