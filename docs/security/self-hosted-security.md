# Self Hosted Security

## Overview

Self-hosted deployments remain responsible for their own infrastructure security.

---

# Customer Responsibilities

```txt
DNS
TLS
Firewall
Backups
Storage
Operating System
```

# Hi5Central Responsibilities

```txt
Application Security Updates
Security Advisories
Documentation
Migration Updates
```

# Recommended Controls

```txt
VPN Access
Restricted Ports
Multi-Factor Authentication
Backup Verification
```
