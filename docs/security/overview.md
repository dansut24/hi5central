# Hi5Central Security Overview

## Overview

Security is a core design principle of Hi5Central.

All platform components are designed using a security-first approach.

This applies to:

```txt
Portal
API
Agent
Viewer
Remote Access
Database
Infrastructure
Self Hosted Deployments
Managed Deployments
```

---

# Security Principles

## Principle 1

```txt
Least Privilege
```

Users and systems receive only the permissions required.

---

## Principle 2

```txt
Zero Trust
```

Every request must be authenticated and authorised.

---

## Principle 3

```txt
Tenant Isolation
```

Customer data must remain isolated.

---

## Principle 4

```txt
Audit Everything
```

Security-sensitive actions must be logged.

---

## Principle 5

```txt
Encryption Everywhere
```

Data must be protected in transit and at rest.
