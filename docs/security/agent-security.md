# Agent Security

## Device Identity

Every agent receives:

```txt
Unique Device ID
Unique Device Key
```

---

# Enrollment

Enrollment must support:

```txt
One-Time Enrollment Tokens
Enrollment Expiry
Enrollment Revocation
```

---

# Agent Validation

Future support:

```txt
Certificate Validation
Mutual TLS
Agent Integrity Verification
```

---

# Agent Actions

All agent actions must be authenticated and authorised.
